# Changelog

Each entry is one version of this template. Breaking changes are listed first.
## 1.40.5-1 (2026-11-16)

- README: Deploy on Railway button for the published template `weaviate-2`. No change to the deployed service.


## 1.40.5 (2026-11-16)

- First release: Weaviate v1.40.5 (`semitechnologies/weaviate:1.40.5@sha256:fe848a3830c8a96fc598c903e39bbaa84a84553e30362663c313643a0febe32a`).
- Data, schema and filesystem backups on one Railway volume at `/var/lib/weaviate`.
- API key required (generated by the template), anonymous access off, RBAC on with the key's user `admin` as root. The container refuses to start without a key.
- REST and GraphQL API on the public domain (`$PORT`, default 8080); gRPC on port 50051 over Railway's private network.
- Fixed node name `node1`, so the schema survives redeploys.
